# PlanBuilder roadmap

The first build is the foundation: drawing, levels, 3D, catalog and estimate all work and agree with each other. Each phase below adds on top of it. Order is a proposal; change it to what pays first.

## Phase 1: done (this build)
- 2D plan editor: walls with typed lengths, rectangle and shaped rooms, doors / windows on walls, placed products, roof sections, measure, snapping (grid, corners, wall lines, 15° angles), undo / redo, split / flip / stretch walls.
- Levels (multi-story), the level below shown as a guide.
- 3D: walls with real door and window openings, room floors and wall colors, doors, windows, garage doors, cabinets / fixtures / appliances, gable / hip / shed / flat roofs with pitch and overhang, parapets, cutaway, walk-through, click-to-select, picture and .glb export.
- Catalog: 72 starting products, add / edit / delete, colors, pictures as 3D textures, CSV import / export.
- Estimate: floors, paint, drywall, siding, baseboard, doors, windows, products, roof covering + accessories + tear-off, hand-added lines, tax, overhead & profit, CSV and print / PDF.
- Projects: templates, save in the browser, export / import.

## Phase 2: shared and connected to the CRM
- Done: **CRM prices**. PlanBuilder reads the CRM's Rate Book, Products, Labor Rates and tax / margin in the same browser and prices linked products and Studio rates from them (read only).
- Next: read prices straight from the CRM's cloud database with the CRM sign-in, so the latest prices arrive even when the CRM has not been opened in that browser; keep the product links in the cloud so the team shares them.
- Sign in with the GrayCo CRM login; save projects and the catalog in the CRM's database (like RoofScout) so the whole team sees them on any device.
- Link a plan to a CRM job / lead / claim; open it from the job; push the estimate into the CRM estimate builder and proposal PDF.
- A 📐 PlanBuilder tab inside the CRM.
- Trace over a picture: load a PDF / photo / satellite image (RoofScout) as an underlay at a known scale and draw on top.

## Phase 3: roofs like a roof report
- One roof from the whole footprint (L, T, U shapes) with valleys and hips worked out automatically; dormers; different pitches per face.
- Roof diagram page with every edge length and pitch (ridge, hip, valley, rake, eave, step flashing, wall flashing).
- Gutters / downspouts, vents, skylights, chimneys and their flashing.

## Phase 4: insurance tools
- Done so far: imported price lists (Xactimate exports or supplier lists), Xactimate codes on products, R&R / replace / remove, room-by-room layout, Xactimate-ready line-item export.
- Sending the sketch and line items straight into Xactimate (ESX) through Verisk's partner program, if GrayCo is approved for it.
- Your own line-item codes per catalog product; remove / replace / detach-reset lines; depreciation, ACV / RCV, recoverable depreciation.
- Damage marking per room / wall / roof face (affected area only), with CompanyCam photos pinned to the plan.
- Scope sheet and supplement tracking (what was added after the first estimate, why).
- Room-by-room report the way adjusters read it.

## Phase 5: building detail
- Stairs tool, cabinet runs that fill a wall, countertop SF, tile per wall (backsplash, tub / shower walls).
- Framing takeoff: studs, plates, headers, sheathing, house wrap, insulation; trusses / rafters; foundation and concrete. *(First pass done in Studio; next: hip / valley framing, point loads, rebar by weight, beam sizing by load.)*
- Electrical, plumbing and HVAC symbols with counts.

## Done since the first build
- Existing / new / demolish phases with before / after; tracing over a picture; architectural styles with roof framing; auto-furnish and decor; renditions; room and house photos; walk-through with walls, room cards and lights; editing in 3D; damage marking; entered estimates with GrayCo price memory; customer view with no prices. Studio: systems budget, x-ray / explode / cutaway, 16-step build timeline, structure and MEP figured from the drawing.

## Phase 6: selling with it
- Customers saving their own renditions from the GrayCo Portal (needs the shared database of Phase 2).
- 360° room photos placed in the walk-through.
- Good / better / best options on the same plan with price differences.
- Better materials and lighting in 3D, saved camera views, a walk-through video.
- Customer view in the GrayCo Portal: 3D model and selections, approve options online.

## Phase 7: commercial
- Ceiling grids, storefront systems, demising walls, door hardware schedules.
- ADA clearance checks, egress / occupancy notes.
- DXF / DWG import and export for architects. *(DXF, PDF and picture import done; next: DXF export, DWG direct, angled walls from pictures, reading dimension text for the scale, door swings from arcs.)*
